## Conservative interpretations (review)
- survive/protect require `turnLimit`, meaning rounds to hold. Progress = completed rounds (`round - 1`).
- interrupt requires the `charging` gimmick plus an interrupt Technique or ACT. Progress is the engine-recorded interrupt count in `objectiveProgress`, written only by C08 `interruptCharge`. Required = 1.
- pacify completes when every enemy-targeted `pacify-progress` ACT is complete, with outcome `pacified`.
- Every objective still ends as `victory` if all enemies reach 0 HP, so ATTACK always stays a valid path.
- `turnLimit` has no timeout meaning for defeat/interrupt/pacify, because the contract gives no basis for a timeout outcome.

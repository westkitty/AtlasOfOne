## Defects (pinned with `it.fails`, labelled DEFECT)
- **Q11-D1 — menu / sheet dialog semantics.** `[data-testid="menu"] .menu` is
  `role="dialog" aria-label="Menu"` without `aria-modal`; `[data-testid="sheet"]` (Vault,
  record) has no dialog role/label. Repro: open the menu, inspect; choose Vault, inspect.
- **Q11-D2 — Enter/Space swallowed on world buttons.** `src/world/TouchControls.tsx`
  (window keydown, ~line 78) calls `preventDefault()` + `onInteract()` for
  `Space`/`KeyE`/`Enter` unless the target is an input/textarea/select, so a focused
  `<button data-testid="open-journal">` does not activate. Repro: focus open-journal,
  press Enter: the composer does not open (and the overworld interact fires instead).
  Suggested fix: also skip when `e.target` is a button/link/`[role=button]`.

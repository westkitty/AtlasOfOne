## Changed behavior

For a validated schema-v1 campaign with an existing `FinalAssessment`:

- v1 -> v2 migration creates exactly one historical `AtlasSnapshot`;
- snapshot ID is deterministic: `snapshot_legacy_<assessment-id>`;
- `createdAt` is the original assessment `generatedAt`;
- `synthesis` preserves the validated legacy assessment exactly;
- legacy `finalAssessment` remains present for compatibility;
- source ID arrays are intentionally empty because schema v1 did not record which exact evidence/insight/contradiction IDs fed the assessment;
- a v1 campaign without a FinalAssessment creates no historical snapshot;
- re-validating already-v2 state does not duplicate the snapshot.

The empty provenance arrays are deliberate evidence honesty, not lost data: inventing source IDs would create false provenance.

## Contract
`deriveAdventureConsequences(state, runId, { exitCause? })` -> `AdventureConsequences` (zod-strict `adventureConsequencesSchema`):
- `runId, seedId, territoryId, templateId | null, resolution ('completed'|'withdrawn'), cause ('finished' | A05 exit cause), combatOutcome | null`
- `worldFlags: { key, runId }[]` — keys (sorted, deduped): `territory:<t>:visited`, `run:<run>:<resolution>`, `territory:<t>:template:<templateId>:<resolution>`, `territory:<t>:encounter:<combatOutcome>`, `run:<run>:thread-open` (paused-for-later).
- `npcAvailability: { npcId, availability: 'present'|'absent', runId }[]` from `run.characterIds` (stable-id only). `absent` only after an escape; never `departed` (fail-forward).
- `memoryCards: AdventureMemory[]` — one per template `memoryOutputs` type on completion; on withdrawal only `character`/`place` (+ `promise` for paused-for-later). Id `mem_<runId>_<type>`, `sourceIds = [runId, seedId]`, trigger terms `[territory, templateId, kind, type]`, summary built only from template title + territory + ending phrase.
- `xpDelta: 0`, `rewardIds/evidenceIds/observationIds: []` enforced by schema (literal 0 / empty-never arrays).

`applyAdventureConsequences(state, consequences)` appends not-yet-present cards to `adventureMemories` and changes nothing else; idempotent (returns the same object when nothing is new); never overwrites an existing card (a privatized/retired card stays so); throws for a missing/active run.

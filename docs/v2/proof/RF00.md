## State-machine semantics

- new reflections begin `pending`, with no decision and no implied human answer;
- Confirm -> `confirmed`;
- Partial -> `partial`;
- Reject -> `rejected`;
- Uncertain -> `uncertain`;
- PRIVATE is orthogonal to epistemic status and structural visibility;
- REVISE stores Greyson's replacement response but returns epistemic status to `pending` until RF05 resolves revision provenance;
- retraction preserves decision/response/history, marks the record retracted, is idempotent, and rejects later decisions.

## Bounded repair found during review

The first RF00 implementation would overwrite an already-substantive Reflection response when a previously decided record was later marked PRIVATE.

That violates the D05 rule that privacy is orthogonal to epistemic history.

Repair:

- PRIVATE now uses the earlier substantive response when one exists;
- the privacy action does not rewrite what Greyson previously said;
- focused test proves a confirmed response `Yes.` survives the later PRIVATE action.

## Contract choice

D05 names `linkedAdventureIds` but does not distinguish seed IDs from run IDs.

J07 freezes the narrow interpretation:

- `linkedReflectionIds` -> existing `ReflectionRecord.id`;
- `linkedAdventureIds` -> existing `AdventureRun.id`.

An AdventureSeed is a proposal/eligibility record, not the history-bearing played adventure.

## Behavior

- target IDs must exist;
- a new Reflection link requires an active Reflection record;
- retracted Journal entries cannot gain new links;
- PRIVATE Journal entries may preserve/add local links, but their provider/content eligibility remains governed by existing privacy selectors;
- duplicate links are idempotent;
- linking never creates Reflection/Adventure records or provider/progression state;
- public export/import preserves the link arrays.

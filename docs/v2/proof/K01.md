## Frozen base score

K01 intentionally scores only the two factors it owns:

- undercoverage: **70 points maximum**
- age since last exploration: **30 points maximum**
- age saturation: **30 days**
- total range: **0..100**

Rules:

- required-dimension coverage is measured structurally;
- duplicate required dimensions and duplicate gap territory IDs cannot inflate weighting;
- multi-territory gaps average factors rather than receiving bonus priority for breadth;
- never-explored territory receives the capped age contribution;
- future exploration timestamps clamp to zero age instead of producing negative urgency;
- current time is injected; the scoring function does not read wall clock;
- unknown territories and invalid timestamps fail closed;
- gap kind/summary/prose cannot affect this score.

Explicit curiosity, contradiction relevance, journal salience, diversity/cooldown, repetition suppression and privacy eligibility remain separate K02-K06 concerns.

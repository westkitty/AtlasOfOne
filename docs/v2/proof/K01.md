## Design choice

The master plan names scoring factors but does not freeze arbitrary numeric weights.

K01 therefore does **not** invent a single weighted personality-priority formula.

It computes two explicit deterministic facts:

1. **undercoverage**
   - unique target dimension count;
   - missing target dimensions;
   - 0..1 missing ratio;

2. **age since last eligible exploration**
   - `neverExplored` remains an explicit boolean;
   - otherwise whole elapsed days;
   - caller supplies `now`; K01 never calls `Date.now()`.

A K01-only comparator produces stable ordering without pretending the remaining K02-K04 factors already exist.

## Ordering contract

Within the K01-only view:

1. larger undercoverage ratio;
2. larger absolute missing-dimension count;
3. never explored before previously explored;
4. older exploration before newer;
5. stable gap ID.

K02-K04 remain responsible for explicit interest, contradiction/change, diversity/cooldown and final stored priority composition.

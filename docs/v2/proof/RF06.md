## Authority model

RF06 does **not** infer semantic contradiction from arbitrary prose.

A later human/model proposal boundary supplies the relationship candidate. TypeScript decides only whether that candidate is allowed to become a durable contradiction record:

- at least two distinct evidence IDs;
- every source exists;
- every source is active and structurally visible;
- source claims are not byte-identical duplicates;
- exact retries are idempotent;
- an existing contradiction over the same evidence set is reused;
- conflicting stable-ID reuse is rejected.

The constructor returns one `ContradictionRecord`; integration owns any eventual shared-state insertion.

## Save behavior

Saving a typed Journal entry:

- uses the J00 `createJournalEntry` + `appendJournalEntry` domain boundary;
- preserves the exact authored text;
- generates the stable local record ID with browser `crypto.randomUUID()`;
- records `inputMode:'typed'`;
- appends only `journalEntries` and updates `updatedAt`;
- triggers the existing whole-campaign IndexedDB autosave;
- does not create a TurnRecord;
- does not create Evidence or Insight;
- does not award XP or progression;
- does not call `/api/turn`;
- closes after save with local feedback.

A synchronous ref excludes same-task duplicate save dispatches. Its focused browser regression dispatches two DOM clicks against one render closure and proves exactly one extra Journal record appears.

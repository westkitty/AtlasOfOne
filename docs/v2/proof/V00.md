## Target lifecycle

`idle -> requesting-permission -> listening -> transcribing -> idle/error`

Provider request/thinking state is ordinary request/UI state and must not be represented as microphone state.

After transcription, editable text remains under player control. Atlas responses are text only. A text response must not reopen the microphone automatically.

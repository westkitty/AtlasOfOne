## Privacy model implemented

Eligibility derives only from IDs, lifecycle status and privacy state.

Two questions are intentionally distinct:

1. **has eligible support** — used for retirement; mixed provenance is not destructively retired while some support remains eligible;
2. **is structurally visible** — stricter; already-written summary/prose is withheld unless every recorded source is eligible.

This prevents mixed public/private provenance from leaking through stored derived text while preserving history.

## Propagation implemented

- JournalEntry eligibility: active + normal privacy;
- Evidence eligibility reuses the existing canonical `createEvidenceVisibility` definition;
- Insight/Contradiction structural visibility follows evidence provenance;
- KnowledgeGap support and visibility follow evidence/journal source IDs;
- AdventureSeed follows source gaps;
- AdventureObservation traces action -> run -> seed -> gap -> source eligibility;
- Reflection follows its typed source kind;
- AdventureMemory generic `sourceIds` resolve only when an ID identifies exactly one known source record; missing or colliding IDs fail closed;
- AtlasSnapshot is eligible as future source only when recorded provenance exists and is structurally visible;
- M03 historical snapshots with unknowable empty provenance remain durable history but are not silently promoted into future source authority.

## Retirement behavior

Only records whose schemas have genuine retirement states are mutated:

- open/seeded KnowledgeGaps -> retired when all recorded support becomes ineligible;
- AdventureSeeds -> retired when all source gaps become ineligible;
- AdventureMemories -> retired when all provenance becomes missing/ambiguous/ineligible.

Resolved gaps, Reflections, Snapshots, AdventureRuns/Actions/Observations remain historical records and are withheld instead of being rewritten.

No `updatedAt` timestamp is fabricated.

## Known gap (schema field needed — not implemented)
Evidence created from a Reflection (RF02 proposal) has no link back to that Reflection: `EvidenceRecord` has only `sourceTurnIds`. So a Reflection going PRIVATE cannot propagate to evidence it produced. Closing this needs a persisted field such as `EvidenceRecord.sourceReflectionIds?: string[]` (in `src/game/types.ts` + persistence schema/migration, both hot zone). Stopped at that boundary.

M06 visibility for Reflections/Insights is strict ("every source eligible"), so a mixed-source Reflection is withheld when any source is withdrawn — stricter than "exclusively relying", by M06 design.

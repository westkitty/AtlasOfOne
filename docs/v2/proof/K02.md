## Behavior

K02 turns one explicit Journal-side “explore this” action into a `KnowledgeGap(kind='curiosity')` candidate.

It deliberately does **not** infer curiosity from Journal prose.

Required conditions:

- source JournalEntry exists;
- source JournalEntry is active and non-private;
- territory and dimension targets are explicit inputs;
- selected territory IDs exist;
- selected dimensions are mapped by the selected territories;
- summary is explicit action/UI wording, not mined prose;
- priority starts at `0`; K01 owns scoring and K04 owns diversity/cooldown;
- same active marker deduplicates;
- conflicting stable-ID reuse is refused;
- resolved/retired historical markers do not block a new explicit curiosity action.

The function returns a record only. It never mutates `CampaignState`.

# Canonical Greyson asset slots

The planning source references canonical Greyson visual assets, but the binary files were not present in the accessible repository/attachment set for this pass.

When supplied, place them here without inventing replacements:

- `greyson-front.png` — sharp pixel front sprite; default map avatar
- `greyson-back.png` — sharp pixel back sprite
- `greyson-side.png` — sharp pixel side sprite; mirror for opposite direction
- `greyson-front-blur.png` — optional transition effect
- `greyson-back-blur.png` — optional transition effect
- `greyson-side-blur.png` — optional transition effect
- `greyson-turnaround.png` — detailed turnaround art; reserve for later Character/Vault/final progression

The UI falls back to a clearly non-canonical placeholder glyph if the sharp front sprite is absent.
